Getting Started

What is Ubuntu Coreaoke?

Ubuntu Coreaoke is a karaoke system that turns any computer into a full karaoke machine. Singers use their phones to search for songs and add themselves to the queue, while you control everything from a simple web page. A TV or projector shows the lyrics and music videos.

How to access it

Open any web browser on a phone, tablet, or computer connected to the same network and go to the address shown on the TV screen. You can also scan the QR code displayed on screen. The default address looks like:

http://your-machine-ip:5555

How to add songs

  • YouTube search: Use the Search page to look up any song on YouTube. Pick the one you want, enter your name, and it gets downloaded and added to the queue.
  • Local files: Use the Browse page to pick from songs that are already downloaded on the machine.

The Display Screen

What the splash screen shows

When no one is singing, the TV shows a splash screen with your logo, a background video, the web address and QR code so people can connect, and the name of the next singer. This is what your audience sees between songs.

How to change the background video

Replace the default background video with your own. Use any MP4 file -- a looping animation, your venue branding, whatever you like.

sudo snap set coreaoke bg-video-path=/path/to/video.mp4

How to change the logo

Put your own logo on the splash screen. A PNG image around 2048x1024 pixels works best.

sudo snap set coreaoke logo-path=/path/to/logo.png

How to change the app name

Replace "Coreaoke" with your own venue name wherever it appears in the interface.

sudo snap set coreaoke app-name="My Venue Karaoke"

Background music

Between songs, background music plays automatically from a folder of MP3 files. You can point it at your own music folder or turn it off entirely. The volume is separate from the main karaoke volume so you can keep it low.

Clock on screen

Show a digital clock on the splash screen so singers and staff can see the time without checking their phones.

sudo snap set coreaoke show-splash-clock=true

Digital Signage

What channels are

Channels let you run different screens on different TVs, all from the same Coreaoke machine. Each channel has its own background video, logo, QR codes, and background music. Think of each channel as a separate "screen layout" you can point a TV at.

Built-in channels

  • main -- The default karaoke screen with lyrics, queue, and everything singers interact with.
  • queue -- A display that shows the current queue so singers can see who is up next without using their phone.
  • lobby -- A welcome screen for your entrance or lobby area with your logo and a QR code to join.

How to point a TV at a channel

Open the channel URL in a browser on the TV you want to use. Just add the channel name to the splash URL:

http://hostname:5555/splash?channel=queue

How to create a custom channel

Create a new folder under the signage directory with the following structure:

my-channel/ channel.yaml bg-video/ logo/ qr/ bg-sound/

The channel.yaml file controls the channel settings -- its name, layout, volume, and which elements to show. Place your files in the matching subfolders.

What goes in each folder

  • bg-video/ -- MP4 files that loop as the background on that screen.
  • logo/ -- A PNG or JPG image displayed as the channel logo.
  • qr/ -- Text files containing URLs. Each .txt file becomes a QR code on screen. The filename (without .txt) is used as the label.
  • bg-sound/ -- MP3 files that play as background music on that channel.

Managing the Queue

How singers add songs

Singers open the web address on their phone, search for a song, type in their name, and tap to add it. The song downloads from YouTube and joins the queue automatically.

How the admin manages the queue

As the admin (the person running the show), you can reorder songs by dragging them, remove individual songs, or clear the entire queue. These controls appear on the Queue page when you are logged in as admin.

How to limit songs per person

Prevent one person from hogging the queue by setting a maximum number of songs each singer can have queued at once.

sudo snap set coreaoke limit-user-songs-by=3

Fair queue / round-robin mode

When fair queue is turned on, the system automatically rotates through singers so everyone gets a turn before anyone goes twice. No one gets bumped to the bottom just because they signed up late.

Admin password

Set a password to lock down admin features like queue management, player controls, and song editing. Without a password, everyone who connects is treated as an admin.

sudo snap set coreaoke admin-password=secret

Audio & Video Settings

Volume control

Set the main playback volume for karaoke songs. This is a value between 0 (silent) and 1 (full volume).

sudo snap set coreaoke volume=0.85

Background music volume

Set the volume for background music that plays between songs, separate from the main karaoke volume. Keep it low so it does not overpower conversation.

sudo snap set coreaoke bg-music-volume=0.3

Streaming format (HLS vs MP4)

HLS is the default and works best in most situations. It starts playing faster because it streams the song in small pieces. MP4 sends the whole file at once, which can work better on older browsers or if you see playback glitches with HLS. Stick with HLS unless you have a reason to switch.

Pitch shifting

Singers can raise or lower the key of a song to better match their voice. The pitch controls appear on the Now Playing page. This adjusts the music in real time without changing the speed.

Audio normalization

Normalization evens out volume differences between songs so one track is not much louder or quieter than the next. This uses extra processing power, so on slower machines it may cause playback hiccups.

AV sync adjustment

If the audio and video are slightly out of sync -- lips moving before or after the words are heard -- you can nudge the timing. A negative value moves audio earlier; a positive value delays it. Most setups do not need this, but some TVs or HDMI setups introduce a small delay.

Song Library

Where songs are stored

Downloaded songs are saved to a folder on the machine. By default this is inside the snap data directory. You can change it to any folder you have access to.

How to use a USB drive for songs

To store songs on a USB drive, first connect the removable-media interface so the snap can access external drives, then set the download path to your USB mount point:

sudo snap connect coreaoke:removable-media sudo snap set coreaoke download-path=/media/usb-drive/karaoke-songs

How to pre-load songs

If you want the machine to come pre-loaded with songs on first boot, provide a URL to a tar archive of song files. The system downloads and extracts them automatically.

sudo snap set coreaoke preseed-url=https://example.com/songs.tar.gz

Supported formats

  • MP4 -- Standard video files with embedded audio. This is what YouTube downloads produce.
  • CDG + MP3 -- The classic karaoke disc format. A CDG file (graphics) paired with an MP3 file (audio) with matching filenames.

Network & Access

Default port and how to change it

Coreaoke runs on port 5555 by default. If that conflicts with something else on your network, change it:

sudo snap set coreaoke port=8080

Headless mode

Headless mode runs the karaoke server without opening a browser window on the machine itself. Useful when the machine is tucked away and you are viewing everything on separate screens over the network.

Autostart on boot

Have Coreaoke start automatically every time the machine powers on, so you never have to remember to launch it.

sudo snap set coreaoke autostart=true

HTTP proxy for YouTube

If your venue network blocks YouTube or routes through a firewall, set an HTTP proxy so song downloads can get through:

sudo snap set coreaoke proxy=http://proxy.example.com:3128

Software Bill of Materials

A Software Bill of Materials (SBOM) is a complete list of every piece of software included in Coreaoke -- every library, tool, and component along with its version and license. Think of it like an ingredients list on a food label. It lets you verify that everything in the system is properly licensed and accounted for.

View the full list at /sbom.
